# Hub Repository Activity

The Hub implementation is developed here, inside `dp-web4/web4/hub`. The standalone `dp-web4/4-hub` repository is a filtered, published mirror of this subtree. Its commit counter is therefore **not an independent development total** and must not be added to Web4 activity counts.

For a cache-resistant, dated snapshot of Web4 + Hestia development activity, see [`../ACTIVITY.md`](../ACTIVITY.md). The snapshot names exact default-branch HEADs and derives counts from Git history rather than GitHub's dynamically rendered repository counters.

When this subtree is republished to `dp-web4/4-hub`, this file travels with it so automated readers of the mirror have an explicit provenance statement even if GitHub UI metadata is stale.
